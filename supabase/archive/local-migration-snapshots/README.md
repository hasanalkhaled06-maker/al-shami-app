# Archived migration snapshots

These 12 files are local migration drafts from the previous repository state. Their version numbers did not match the live Supabase migration history, so they are preserved here for audit only and are outside `supabase/migrations`.

The active migration directory was reconstructed from the 50 versioned SQL entries recorded in the production project's `supabase_migrations.schema_migrations` table. Do not apply the archived snapshots. The unrecorded `staff_login_accounts` draft is represented by the new forward migration in the active directory.
